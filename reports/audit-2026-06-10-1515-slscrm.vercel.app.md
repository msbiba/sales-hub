## Detailed Findings (per page)

### https://slscrm.vercel.app/landing
- **Elements exercised:** hero CTAs (`#termin`, `#rechner`), hero lead-form (PLZ + Hausnummer + E-Mail + Submit), Kunden-Login + Termin nav, three calculator sliders (Dachfläche / Stromverbrauch / Strompreis), Dach-Typ select, "bereits PV"-checkbox, calculator email-capture, FAQ accordion (5 items, opened #02), Cal.com inline embed, footer links.
- **Console summary:** 0 errors, 2 warnings — both from `app.cal.com` font preload (third-party). Raw: `assets/raw/console-baseline.log`
- **Network summary:** 79 requests, all 2xx/204. ~57 chunks from `app.cal.com` iframe. GA `region1.google-analytics.com/g/collect` and `o574544.ingest.us.sentry.io` envelope fire on load. Raw: `assets/raw/network-baseline.log`
- **Performance:** TTFB 17 ms, FCP **4612 ms**, DOMContentLoaded 4496 ms, load 4937 ms. Hero image ~213 KB (Unsplash). Raw: `assets/raw/perf.json`
- **Responsive:** No horizontal overflow at 375 / 768 / 1280 / 1920 (`assets/viewport-*.png`).
- **Functional:** All probed widgets work — slider 1000→5000 m² updates calculator dd values; FAQ aria-expanded toggles single-open; native HTML5 validation fires on empty hero submit (`Fülle dieses Feld aus.`); stat counters in "Was zählt"-section animate from 0 to 480+/142 MWp/Ø 7,4 J. on IntersectionObserver entry.
- **Issues:** F-001 … F-014

## Recommendations (prioritized)

1. **Critical fixes (now):**
   - Gate GA + Sentry behind explicit consent or correct the DSGVO claim (F-004).
   - Add `<main>` landmark and skip-link (F-001, F-005).
   - Add label to calculator e-mail input (F-003).

2. **High-impact UX / performance:**
   - Lazy-load Cal.com embed on user gesture or scroll (F-002, F-011) — biggest single FCP/LCP win.
   - Add `autocomplete` on hero form, enlarge small tap targets (F-006, F-010).
   - Add SEO + social meta (F-009).

3. **Technical / maintainability:**
   - Add `scope` to table `<th>` and `aria-controls` to FAQ buttons (F-007, F-008).
   - Render final stat-counter values in HTML for no-JS / reduced-motion (F-014).
   - Increase footer link padding (F-012).
